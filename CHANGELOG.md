# Changelog

## 1.0.0-rc1 — 2026-08-25
- Re-audited the build against the user-supplied 2020 Core Rulebook, using the Quick Start only as a secondary cross-check.
- Corrected Core authority values including Stack Attributes starting at 30, SP1 → Attribute +1d4, Damage Threshold = Strength, sleeve Health formulas, advancement costs and resleeving consequences.
- Added the complete 32-Skill mechanical set, 240 Traits, 30 Baggage outcomes, 21 statuses, 3 Injuries and 17 Scandals.
- Added complete private source-backed reference datasets for Sleeve rules, Chapter 6 equipment/technology and Chapter 7 GM procedures.
- Expanded character resources, Ego, Wealth/Deferral/Credits, Resource Catalogs, Tech Points, Cargo, Requests/Networks, Virtual, viral, vehicle, backup, Minion/Nemesis and AI/Religious/Envoy/Meth mechanics.
- Corrected Catastrophe handling so a successful Bonus Die does not erase a natural failed max Skill + max Luck Catastrophe.
- Corrected Speed Dice to the Core natural maximum of five after modifiers.
- Added source-correct DP-on-Use Depletion resolution and same-Skill-die Depletion Checks.
- Added operational Weapon/Equipment Use workflows, firing-mode modifiers and damage/state chat-card controls.
- Added explicit aggregate-Protection application timing and Real Death/resleeving controls.
- Migrated Cold Storage pregens/resources to corrected Core values and added Meth variant starting benefits/backup.
- Expanded static/content QA to 48 passing tests.
