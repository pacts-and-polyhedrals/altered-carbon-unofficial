# Testing

Run `npm test` for pure rule and content tests, and `npm run validate` for manifests/content invariants. A licensed Foundry v14 runtime is still required for final API integration, sheet rendering, socket and permission tests.

Six-player acceptance checklist: ownership; private dossiers; private memory; Speed Dice commitment; opposed checks; damage/Ego/depletion; sleeve activation; identity reveal; relationship permissions; scene loading; reconnection; reserve reassignment.
